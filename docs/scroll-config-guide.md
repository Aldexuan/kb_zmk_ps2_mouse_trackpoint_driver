# 滚轮模式配置指南

## 概述

滚轮模式通过 `scroll-layer` DTS 属性启用：当指定的 layer 是当前最高激活层时，TrackPoint 的移动会被转换为滚轮事件。

新版滚轮逻辑使用**累加器 + 动态除数**算法，替代了之前的硬编码分段缩放，提供更平滑、更可控的滚轮体验。

## 对低功耗的影响

**无影响**。滚轮逻辑只在 scroll layer 激活时运行，且位于 `input_report_rel()` 的下游。`input_mouse_ps2.c` 里的 deadzone=1 过滤在更上游就拦截了噪声包，不会触发 listener，不会重置 ZMK idle 计时器。

## DTS 配置参数

在你的 `mouse_ps2_input_listener` 节点中配置：

```dts
mouse_ps2_input_listener: mouse_ps2_input_listener {
    compatible = "zmk,input-listener-ps2";
    status = "okay";
    device = <&mouse_ps2>;

    /* 基础配置 */
    xy-swap;
    x-invert;
    y-invert;
    scroll-layer = <4>;          /* 哪个 layer 激活时进入滚轮模式 */

    /* 滚轮调参（以下为默认值，可按需调整） */
    scroll-deadzone = <2>;       /* 噪声过滤阈值 */
    scroll-divisor-slow = <60>;  /* 慢速滚动除数 */
    scroll-divisor-fast = <20>;  /* 快速滚动除数 */
    scroll-input-max = <128>;    /* 输入幅度上限 */
    scroll-dominant-axis;        /* 启用主导轴锁定 */
};
```

## 参数详解

### scroll-deadzone（默认 2）

**作用**：低于此值的输入被视为噪声，直接丢弃并清零累加器。

| 值 | 效果 |
|---|---|
| 0 | 无死区，任何微小移动都会累积（可能产生意外滚动） |
| 1 | 极小死区，非常灵敏 |
| **2** | **推荐**，过滤 TP 静止噪声 |
| 3-5 | 较大死区，需要更明显的推力才开始滚动 |

### scroll-divisor-slow（默认 60）

**作用**：慢速移动时的除数。越大 = 需要更多输入才产生一个滚轮 tick = 更精细的控制。

**调参建议**：
- 觉得慢速滚动太灵敏（轻碰就滚）→ 调大，如 80-100
- 觉得慢速滚动太迟钝（推很久才滚一格）→ 调小，如 40-50

### scroll-divisor-fast（默认 20）

**作用**：快速移动时的除数。越小 = 快速滑动时滚得越快。

**调参建议**：
- 觉得快速翻页不够快 → 调小，如 10-15
- 觉得快速翻页太快失控 → 调大，如 30-40

### scroll-input-max（默认 128）

**作用**：输入幅度的上限。超过此值按此值计算。决定了"从慢到快"的过渡区间。

**一般不需要调**。TP 在 100Hz 采样率下单包最大约 127，128 刚好覆盖全范围。

### scroll-dominant-axis（默认关闭）

**作用**：启用后，滚轮模式会锁定到主导轴（位移更大的那个轴），另一个轴归零。

**判定规则**：
- Y 轴位移 > X 轴位移 × 1.5 → 纯竖向滚动（X=0）
- X 轴位移 > Y 轴位移 × 1.5 → 纯横向滚动（Y=0）
- 两轴差距不够大（对角线区域）→ 双轴归零（不滚动）

**适合**：
- 习惯精确竖向/横向滚动的用户
- TP 操作时手指容易斜向偏移的用户

**不适合**：
- 需要对角线滚动的场景（如地图、画布）

## 算法原理

```
输入 delta → 死区检查 → 主导轴锁定 → 累加器 += delta → 动态除数计算 → tick = 累加器 / 除数
                ↓                                                              ↓
          |delta| ≤ 2:                                              tick ≠ 0: 发送 HID 报告
          清零累加器                                                 累加器 %= 除数（保留余数）
          不产生输出
```

**动态除数**：在 `divisor_slow` 和 `divisor_fast` 之间线性插值：
```
divisor = slow - (slow - fast) × |delta| / input_max
```
- 轻推（|delta|=3）→ divisor ≈ 59 → 需要累积很多才滚一格
- 重推（|delta|=100）→ divisor ≈ 29 → 很快就滚一格

**累加器**：小位移不会丢失。比如 divisor=60 时，连续 60 个 delta=1 的包会累积到 60，然后输出 1 tick。这比之前"小于 3 直接丢弃"的做法平滑得多。

## 与旧版行为的对比

| 特性 | 旧版（硬编码分段） | 新版（累加器+动态除数） |
|---|---|---|
| 慢速滚动 | `|val|<3` 直接丢弃 | 累积到阈值才输出，不丢失 |
| 速度曲线 | 6 段硬编码阈值 | 连续线性插值，更平滑 |
| 噪声过滤 | 无专门处理 | deadzone + 累加器清零 |
| 方向锁定 | 无 | 可选主导轴锁定 |
| 可配置性 | 需要改代码 | DTS 参数，编译时配置 |

## 快速调参建议

| 使用场景 | 推荐配置 |
|---|---|
| 浏览网页（精确滚动） | deadzone=2, slow=80, fast=20 |
| 代码编辑（快速翻页） | deadzone=2, slow=40, fast=10 |
| 通用平衡 | deadzone=2, slow=60, fast=20（默认） |
| 高灵敏度 TP | deadzone=3, slow=80, fast=30 |
