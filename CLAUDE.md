# Guidelines
- Language: Always use Simplified Chinese (简体中文) for all explanations, responses, tool descriptions, and interactive prompts.
- Code Comments: Keep original code comments in English.
- Style: Concise and direct.
- Workflow: If the user's prompt contains the word "分析" (Analyze/Analysis), DO NOT modify or edit any files immediately. First output a detailed analysis document and proposed solution, then wait for explicit approval before making changes.
- Interactive Prompts: When asking questions, requesting confirmation, or providing choices/options in the console (e.g., Tool Approvals or CLI Menus), always write all option descriptions and instructions in Simplified Chinese (简体中文).
